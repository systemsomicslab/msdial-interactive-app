Add analysis data

Raw data are referenced at their original paths and are never copied into this app.

Use Add original files for file-type data such as WIFF, mzML, ABF, or Thermo RAW. Use Add vendor folders for folder-type data such as Agilent .d, Bruker .d, or Waters .raw; multiple vendor folders can be selected in the local path browser. Browser drag-and-drop cannot reliably expose original absolute paths, so this app references local paths through the path browser or Add path.

Parameter templates and demo data are available from the Console app tutorial. Demo packages: LC-MS/MS lipidomics and GC-MS.

Single-file diagnostic run

Runs the selected file with Minimum peak height = 0 and all MSP cutoffs = 0. Alignment is disabled. The selected Mass slice width is used.

Required: LC-MS project, one imported analysis file, an existing MS-DIAL Console path, parameter template, and output folder. WIFF import accepts the primary file alone, but SCIEX processing requires its adjacent WIFF.SCAN to remain accessible.
