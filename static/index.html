RT correction review workspace

Detect anchor peaks, inspect and correct the selected RTs, then save an approved selection TSV for the main MS-DIAL analysis.
Goal of this workspace Produce an approved peak-selection TSV. The main app combines that file with the selected anchor library and enables RT correction in the production MS-DIAL run.

Anchor EICs use MS-DIAL's configured LinearWeightedMovingAverage smoothing (default level 3, ±3 points). Automatic peak detection is the same Core process used by the GUI. Weighted selection uses (1 - RT weight) × relative height + RT weight × proximity to reference RT; both terms range from 0 to 1.
